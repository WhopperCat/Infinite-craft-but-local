# Infinite Craft — Local AI

An [Infinite Craft](https://neal.fun/infinite-craft/) clone that runs the AI
**entirely in your browser** via WebGPU — no server-side inference, no API keys.
Deployed as a Cloudflare Worker that simply serves the static front-end.

## How it works

Drag two elements together on the canvas and they combine into something new.
Combinations are resolved in three layers:

1. **Seed cache** — ~50 hand-authored combos with emojis (instant).
2. **localStorage** — every combo you discover is remembered locally.
3. **On-device AI** — anything else is generated by a tiny instruct model
   (`onnx-community/Falcon-H1-Tiny-90M-Instruct-ONNX`, q4f16) running on WebGPU
   inside a Web Worker.

Same pair always gives the same result (deterministic via the cache layers).

## Requirements

- A WebGPU-capable browser: **Chrome 113+ on desktop**.
- ~97 MB one-time model download (cached by the browser afterwards).

## Project structure

```
/
├── wrangler.toml         # Cloudflare Worker config
├── package.json
├── worker-entry.js       # Worker entry — serves /public as static assets
└── public/
    ├── index.html
    ├── style.css
    ├── worker.js         # AI inference Web Worker (browser-side)
    ├── cache.js          # Seed cache + localStorage logic
    ├── ui.js             # DOM, toasts, animations, loading screen
    └── game.js           # Core game logic, drag/drop, state
```

## Develop & deploy

```bash
npm install
npm run dev      # local dev server via wrangler
npm run deploy   # deploy to Cloudflare Workers
```

## Controls

- **Drag** an element from the sidebar onto the canvas.
- **Drag** one canvas element onto another to combine them.
- **Double-click** a canvas element to remove it.
- **Clear canvas** wipes the board but keeps your discovered elements.
